Auto-Sync Real-Time

Kirim mutasi seketika setiap kali transaksi dicatat atau dihapus.

📖 Panduan 3 Langkah Sambungkan Sheets

1. Buka file Google Sheets Anda di browser > pilih menu Ekstensi > Apps Script.

2. Hapus kode yang ada, tempel kode di bawah ini, lalu klik Deploy (Terapkan) > Penerapan baru.

3. Pilih jenis: Aplikasi Web, Jalankan sebagai: Saya, Akses: Siapa saja, lalu salin URL Webhook dan tempel di formulir atas.

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);

  // Jika spreadsheet masih kosong, buatkan judul kolom otomatis
  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      'Waktu Transaksi',
      'Nama Pemilik',
      'Tipe Mutasi',
      'Kategori',
      'Dompet / Rekening',
      'Nominal (Rp)',
      'Keterangan Transaksi'
    ]);
  }

  // Tambah baris transaksi seketika (Real-Time Auto Sync)
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString('id-ID'),
    data.userName,
    data.type === 'INCOME' ? 'Pemasukan (+)' : 'Pengeluaran (-)',
    data.category,
    data.walletName,
    data.amountFormatted || data.amount,
    data.note
  ]);

  return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}

Skema Database Cloud (Supabase Multi-User)

-- SKEMA SAKUKITA MULTI-USER & GOOGLE PROFILE
CREATE TABLE users (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  google_name TEXT NOT NULL,
  google_email TEXT UNIQUE NOT NULL,
  avatar TEXT DEFAULT '👤',
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE spaces (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  name TEXT NOT NULL,
  owner_id UUID REFERENCES users(id),
  budget NUMERIC DEFAULT 6000000,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- HAK AKSES HANYA PANTAU (VIEWER PERMISSIONS)
CREATE TABLE space_permissions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  space_id UUID REFERENCES spaces(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  role TEXT CHECK (role IN ('VIEWER')), -- HANYA BISA MEMANTAU!
  UNIQUE(space_id, user_id)
);

CREATE TABLE transactions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  space_id UUID REFERENCES spaces(id) ON DELETE CASCADE,
  created_by_user_id UUID REFERENCES users(id),
  amount NUMERIC NOT NULL,
  type TEXT CHECK (type IN ('INCOME', 'EXPENSE')),
  category TEXT NOT NULL,
  note TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- REALTIME SYNC UNTUK SELURUH HP KELUARGA
ALTER PUBLICATION supabase_realtime ADD TABLE transactions;
ALTER PUBLICATION supabase_realtime ADD TABLE spaces;

Pasang Aplikasi Siap Pakai

Langsung muncul di layar HP Anda tanpa instalasi ribet
SakuKita Sudah Siap Pasang!

Aplikasi ini berbasis Progressive Web App (PWA). Begitu dipasang, ikon SakuKita akan langsung muncul di HP Anda seperti aplikasi APK dari Play Store atau App Store.

Android
Cara Pasang di HP Android (Google Chrome):
  1. Cukup klik tombol "📲 Pasang Sekarang" di bilah atas aplikasi.
  2. Atau tap menu titik tiga (⋮) di pojok kanan atas Chrome.
  3. Pilih "Instal Aplikasi" atau "Tambahkan ke Layar Utama".
  4. Selesai! Ikon SakuKita siap dibuka kapan saja dari menu HP.
iPhone
Cara Pasang di iPhone / iPad (Safari):
  1. Buka link aplikasi ini di browser Safari.
  2. Tap tombol Bagikan (Share ⎋) di bar bawah Safari.
  3. Gulir ke bawah dan pilih "Tambah ke Layar Utama (Add to Home Screen)".
  4. Tap "Tambah" di pojok kanan atas. Selesai!
Laptop
Cara Pasang di Komputer / Laptop (Windows & Mac):

Klik tombol "Pasang Sekarang" atau klik ikon komputer kecil di bilah URL Chrome/Edge untuk memasang sebagai aplikasi desktop mandiri.
